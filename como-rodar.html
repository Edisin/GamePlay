Como rodar o GamePlay no seu PC

O projeto vem no gameplay.zip, sem a pasta node_modules: as dependências são baixadas no passo 3. Leva poucos minutos.

Expo SDK 57 React Native 0.86 TypeScript

Antes de começar

É preciso ter o Node.js 20.19.4+, 22.13+ ou 24.3+ (exigência do React Native 0.86). Para conferir a versão:

node -v

Se o comando não existir ou a versão for mais antiga, instale a versão LTS em nodejs.org e abra um terminal novo. Para ver no celular, instale o app Expo Go (Play Store ou App Store).

Passo a passo

  1. Extraia o zip

    Botão direito em gameplay.zip → Extrair tudo. Vai surgir a pasta gameplay.

  2. Abra um terminal dentro da pasta

    No Explorador de Arquivos, entre na pasta gameplay, clique na barra de endereço, digite cmd e aperte Enter. No VS Code: Arquivo → Abrir pasta e depois Terminal → Novo terminal.

  3. Instale as dependências

    npm install

  4. Inicie o projeto

    npx expo start

  5. Abra o app

    • Celular: escaneie o QR code do terminal com o Expo Go (Android) ou com a câmera (iPhone). O celular precisa estar no mesmo Wi-Fi do PC.
    • Navegador: aperte w no terminal.
    • Emulador Android (se tiver o Android Studio): aperte a.

Roteiro para testar: Entrar com Discord leva à Home → toque numa partida para abrir os Detalhes → a seta volta → o botão + abre o Agendar → toque nas categorias para ver a troca de estado.

Se algo der errado

“npm” ou “npx” não é reconhecido
O Node não está instalado ou o terminal foi aberto antes da instalação. Instale o Node LTS e abra um terminal novo.
“A execução de scripts foi desabilitada neste sistema”
É uma restrição do PowerShell. Use o Prompt de Comando (cmd), como no passo 2.
Aviso “EBADENGINE” ou erro de versão no npm install
O Node está numa versão antiga. Atualize para a LTS atual.
O celular não abre o projeto ou fica carregando
Confira se PC e celular estão no mesmo Wi-Fi e, se o Windows perguntar sobre o firewall, permita o Node.js. Se a rede bloquear a conexão (comum em redes de faculdade), use o modo túnel e aceite instalar o @expo/ngrok:
npx expo start --tunnel
O Expo Go diz que o SDK do projeto é incompatível
O Expo Go só roda a versão mais recente do SDK. Atualize o projeto ou use a versão do navegador (w):
npx expo install expo@latest --fix
“Port 8081 is being used”
Responda Y para usar outra porta.
Tela branca ou erro estranho depois de mexer nos arquivos
Reinicie limpando o cache:
npx expo start -c

Implementado

  • Detalhes do servidor

Os dados de exemplo ficam em src/data/mock.ts.

src/screens/as quatro telas, cada uma com index.tsx e styles.ts
src/components/componentes reutilizáveis (Button, Header, CategorySelect…)
src/global/styles/theme.tscores, degradês e fontes tirados do Figma
src/routes/navegação entre as telas
src/data/categorias e dados de exemplo
